# TVD-Gate 安装与加装工艺

## 1. 不停水外夹方案（推荐默认）

1. 选定法定取水断面下游、满足直管段处的抱箍位置（与原表传感器错开约 90° 方位更佳）。  
2. 除锈、测外径壁厚、涂耦合剂，安装常驻外夹探头 + 防护罩（防踩踏、防暴晒）。  
3. 探头电缆穿管进入 Gate 箱，独立积算。  
4. 在原表→RTU 的 RS485（或脉冲/电流）上串入 **故障直通型只听分接盒**。  
5. 固定 Gate 箱、接地、防雷、供电；配置户键、许可配额、通信参数。  
6. 联调：确认原平台数据不断、不跳变；Gate 三路同时有数。  
7. 电子铅封、开箱告警启用；出具《加装验收单》。

## 2. 只听分接盒要求（关键）

- 正常：高阻旁听，不增加原总线负载超限  
- 失电/故障：继电器/硬件旁路 **自动直通**，原监测不受影响  
- 光电/磁耦隔离，防雷分级  
- 具备“旁听帧计数 / CRC 错误率”自诊断  

## 3. 方③业务数据如何进设备（三种落地）

| 方式 | 做法 | 适用 |
|------|------|------|
| A 汇聚下发 | 县内网服务按月/税期把直报量、纳税水量推到 Gate | 规上密集县 |
| B 巡检写入 | 执法/统计人员用加密 U 盘/手持把摘要写入 | 网络差的点 |
| C 接口镜像 | 在已有监测/协同渠道旁路订阅结构化字段 | 信息化较好地区 |

均只传摘要字段，不传原始申报附件。

## 4. 验收指标（加装点）

- 原远传中断时间：加装过程目标 0（外夹）或按批准的计划停水窗口  
- ①与②在稳定流下 24h 相对偏差基线录入  
- 人为制造通信异常时，Gate 能区分“物理流正常但镜像中断”  
- 超 5% 月偏差能自动出事件记录  

## 5. 运维

- 外夹耦合剂/抱箍紧固：季度巡检  
- 标准通道：按证书周期拆下送校或用便携 TVD-300 复核  
- 开箱、供电、防雷：月检
