# TVD-Gate 电气要点（加装型）

## 三路输入

```
[外夹核查探头]──独立积算──► Gate CPU  方①
[原表]──►[只听分接·故障直通]──旁听──► Gate CPU  方②
[县汇聚/U盘]──直报·税·许可摘要──► Gate CPU  方③
```

## 控制器最小配置

- MCU/工控：实时采集 + Linux 应用（规则引擎）  
- 存储：eMMC/SSD 加密分区  
- 通信：以太网；4G 可选（仅事件）  
- IO：RS485 旁听口、核查表口、开关量（开箱）、12/24V 电源  
- 安全：硬件看门狗；蜂窝物理拨码  

## 同步

方①②共用本地晶振秒脉冲对齐；方③按业务周期戳对齐（抄表日/税期），允许配置 ±N 天容差窗后算相对偏差。

## 与原 RTU 关系

**不加串破坏性网关**。不做“替换远传”；只旁听 + 独立测。避免与现有监测合格性、网络安全域冲突。
