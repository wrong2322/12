# TVD-Gate 取水口多方数据校验加装装置（常驻型）

> **主方案**：现场加装、长期在线，不是便携比测巡检仪。  
> 目标：在**不拆原表、尽量不停水、不新建大平台**的前提下，用加装器物持续做「独立计量 ↔ 原监测链路 ↔ 直报/税费业务量」三方校验。

## 0. 和「比测」的本质区别

| | 比测（TVD-300 巡检箱） | **加装校验（TVD-Gate，本方案）** |
|--|------------------------|-----------------------------------|
| 驻留方式 | 人带设备到场，测完就走 | **固定加装在取水口/计量井** |
| 时间属性 | 抽检快照 | **7×24 连续比对与告警** |
| 数据关系 | 标准表 vs 在用表 | **旁路独立计量 + 原表/远传镜像 + 业务侧水量** |
| 产出 | 单次校验报告 | **持续偏差曲线、月/税期自动对账、销号工单触发** |
| 适用 | 问题点抽查、送校前后复核 | 规上自备、公共供水关键取水口常态化管控 |

TVD-300 可降级为 Gate 的便携运维工具；**研发主线改为 Gate 加装体系**。

## 1. 「三方」在加装方案里指什么

现场加装后，终端内并行三路真源（业务上对接许可约束）：

```
方① 独立核查计量（加装旁路传感器）     ← 物理水量，设备自己测
方② 原监测链路镜像（原表/RTU 通信旁听） ← “系统里认为的监测数”
方③ 业务申报水量（直报 + 税费周期量）   ← 统计/纳税口径（结构化下发）
        └─ 许可配额/计划用水作约束边界（超许可强制告警）
```

- ① vs ②：发现「表具漂移 / 运维造假 / 远传篡改 / 链路不一致」  
- ①或② vs ③：发现「直报/税基与实灌水量偏离 >5%」  
- 相对许可：计量超许可、证照失效仍取水等强制线索  

这才是**用加装设备做三方校验**，而不是派人拿标准表比一下。

## 2. 加装器物清单（一套点位）

### 2.1 旁路独立计量件（方①）
- **首选**：外夹式时差超声探头 **常驻抱箍安装**（不停水、不破管）  
- **备选**：插入式超声/电磁管段（具备停水窗口时）  
- 独立积算模块，与原结算表电气隔离  

### 2.2 原链路镜像件（方②）
- **RS485 只听分流器 / 光电隔离分接盒**（串在原表→RTU 之间，透明旁听，不改变原远传）  
- 或脉冲光电隔离分接、4–20mA 环路隔离采集  
- 关键原则：**故障断开时原监测链路自动直通**，加装故障不影响原合规远传  

### 2.3 多方校验控制器（核心箱）
- 壁挂/立柱不锈钢箱（IP65），装于计量井旁或泵房  
- 同步时基采集 ①②，本地算偏差与强制规则  
- 接收方③：县级汇聚节点定时下发「直报量、纳税水量、税期、许可配额」结构化包（MQTT/专网/U 盾拷贝均可）  
- 本地存储 ≥1 年分钟级统计；超阈自动生成工单事件  
- 4G/专网上报**事件与对账摘要**（默认不上原始波形）；也可纯本地 + 巡检拷贝  

### 2.4 辅助件
- 电子铅封 / 开箱告警、可选枪机看门（装表位置、井盖）  
- 市电 + 蓄电池/太阳能（野外取水口）  
- 防雷、接地、加热除湿（井下凝露）

## 3. 系统拓扑（加装后）

```
              ┌──────── 原有远传（保持不变）────────┐
取水管道 ─原表─┤                                    ├─► 原监测平台
              └─►【只听分接】─►┐                     │
外夹核查表 ───────────────►  TVD-Gate 控制器 ─事件─►├─► 县级校验汇聚（可复用现有通道）
县级下发 直报/税/许可摘要 ─►┘        │             │
                                     └─本地销号线索┘
```

**不新建综合性应用平台**：汇聚端可以是现有水行政主管部门内网一小套服务，或干脆 U 盘/专网文件交换；现场智能在 Gate 箱内完成。

## 4. 常驻校验逻辑（设备内）

1. **秒/分钟级**：①独立流量 vs ②镜像流量 → 链路/表具一致性  
2. **日级**：累计水量闭合，跳变/离线/异常大数据标记  
3. **月/税期级**：①或审定监测累计 vs ③直报/纳税水量，相对偏差 >5% 触发工单  
4. **持续**：对比许可配额/证照有效期 → 强制违规事件  
5. **公共供水点**：支持转入/转出脉冲或通信接入，做转供不平衡辅助（可选模块）

边缘仍可用「规则优先 + 多模型」对事件分类与派单建议，但模型跑在 **加装箱/县级汇聚机**，不是网页业务系统。

## 5. 加装条件与点位选择（问题导向）

优先加装：
- 规上自备、历史修正记录多、直报与监测常超 5%  
- 公共供水源头表、县际转供矛盾点  
- 模拟信号/易失准点（加装数字核查通道）  

暂缓：山区海岛小型取水口（以台账+抽测为主，不强行全面加装远传核查）。

## 6. 型号

| 型号 | 说明 |
|------|------|
| **TVD-Gate-S** | 单管规上自备标准型（旁路外夹 + 只听分接 + 控制器） |
| **TVD-Gate-P** | 公共供水型（增加转供口、双路累计） |
| **TVD-Gate-M** | 明渠/非满管扩展（多普勒+液位） |
| TVD-300 | 仅作抽检/验收便携工具（非主方案） |

## 7. 合规边界（必须写进说明书）

- 加装核查表用于 **管理校验与销号线索**；贸易结算、法定水量争议以法定计量器具检定/校准结论为准。  
- 旁路外夹通道建议按企业最高计量标准或核查标准送校。  
- 只听分接不得破坏原有型评/强检状态；采用隔离、故障直通设计。  
- 税务侧只交换 **纳税水量结构化数**，不存票面原文。
