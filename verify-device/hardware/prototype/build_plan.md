# 样机试制路线（实物优先）

## 阶段 0 — 概念验证（2–3 周量级工作量，非日历承诺）
- 采购：成熟便携超声流量计（作标准通道黑盒）+ 工业平板 + 隔离 RS485/脉冲采集模块 + GNSS 天线 + 相机  
- 用航空箱改装配：验证“同步采样 + 多方 JSON 对账 + 出单”全流程  
- 软件：本仓库 CLI/编排库 + 简易本地 GUI  

## 阶段 1 — 工程样机
- 定制箱体与面板开孔  
- 采集板打样（Sheet 03）  
- 超声模块二次开发协议对接（替换黑盒手动读数）  
- 送计量院/授权机构对标准通道校准  

## 阶段 2 — 小试
- 选 1 个公共供水矛盾点 + 1 个规上自备点实流比测  
- 记录示值误差、链路一致性、工单销号可用性  
- 修订夹具与直管段作业指导书  

## 阶段 3 — 定型
- 开模、EMC、环境试验、企业标准/检验规程  
- 专利与软著申报材料固化  

## 现场安全与合规
- 不停水作业优先外夹；涉及电气接线必须断电或由持证电工操作  
- 比测数据用于管理核查与销号线索；贸易结算争议仍以法定检定/校准结论为准  
- 设备本身需周期送校，证书随箱
