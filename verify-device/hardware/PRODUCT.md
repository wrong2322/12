# TVD-300 取水计量多方现场校验终端 — 产品定义书

> 实物设备，不是网页。面向县级水行政主管部门、计量技术机构、供水企业现场班组。  
> 解决「许可—监测—直报—税费」现场对账缺统一器物、缺证据固化、缺边缘研判的问题。

## 1. 一句话

一台可背负的加固箱式终端：用**外夹式超声标准通道**比测在用表，用**多协议直采口**核验监测链路真值，在边缘侧完成**多方偏差与强制违规研判**，当场固化证据并打印/导出销号工单包。

## 2. 为什么不是“再买一台便携超声表”

| 现有器物 | 能做什么 | 缺口 |
|----------|----------|------|
| 便携外夹超声流量计 | 标准表瞬时/累计比对 | 不采被检表通信口；不对许可/直报/税；无断面定位证据 |
| 流量计在线检测仪（信号源类） | 模拟 4–20mA/脉冲测二次仪表 | 不测真实水流；不做业务多方对账 |
| 明渠便携比对仪 | 堰槽液位/流量比对 | 主场景非满管取水口；无税费/许可销号出口 |
| 固定 RTU | 远传监测 | 不能当移动标准器；不做现场销号 |

TVD-300 把 **物理比测 + 链路直采 + 业务多方对齐 + 边缘模型 + 证据链** 做进同一台设备。

## 3. 主机形态

- 形态：手提加固箱（约 450×350×180 mm，整机含探头组 ≤12 kg）
- 防护：主机 IP65；探头线缆航空插头快拆
- 供电：26V/10Ah 锂电，满载续航 ≥6 h；支持车载 12/24V 充电
- 人机：10.1" 阳光可视触控；物理急停/锁屏键；热敏打印机仓
- 定位：GNSS（北斗优先）+ 可选 RTK 差分口
- 取证：800 万工业相机 + LED 补光；一键拍铭牌/装表位置/铅封

## 4. 功能模块（实物）

1. **标准计量模组**：时差法双声道外夹探头套件（DN50–DN2000，V/Z 法夹具）+ 超声测厚仪一体口  
2. **被检直采模组**：隔离 RS485×2（Modbus RTU）、脉冲×2、4–20mA×2、可选 RJ45  
3. **边缘计算模组**：工控主板 + NPU/GPU（本地跑规则引擎与五角色模型，默认可离线）  
4. **业务对齐模组**：加密 TF/SSD；扫码枪口；许可/名录/税期摘要离线包导入（不存税务原文）  
5. **证据与输出模组**：相机、热敏打印、PDF/JSON 工单包导出（USB/国密 U 盘）

## 5. 现场一次作业闭环（器物级）

1. 到点 → GNSS 核对是否法定取水断面（偏差超阈告警）  
2. 测厚/外径 → 装标准探头 → 耦合确认  
3. 接被检表通信/脉冲 → 同步采样窗口（≥10 min 或规程点数）  
4. 导入/扫入本户许可配额与直报、税期摘要  
5. 边缘机算出：示值误差、链路一致性、多方相对偏差、强制违规码  
6. 拍照留证 → 打印《现场校验与销号建议单》→ 加密导出证据包  

## 6. 型号规划

| 型号 | 定位 |
|------|------|
| TVD-300A | 管道满管主型（本文件默认） |
| TVD-300B | A + 明渠多普勒/液位比对扩展舱 |
| TVD-300C | 车载固定安装版（县巡检车） |

## 7. 验收指标（样机级）

- 标准通道准确度：优于被检表一个准确度等级，目标 ≤±0.5%（需送法定机构校准）  
- 直采与二次表显示一致性：瞬时/累计完全一致（链路核验）  
- 相对偏差触发：可配置，默认 5%  
- 离线完整作业：无公网可出工单包  
- 温湿度：-10～50℃，≤85% RH（非凝露）
