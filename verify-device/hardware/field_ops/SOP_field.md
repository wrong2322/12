# 现场作业指导书（器物操作）

## 出车前
- [ ] 电量 ≥60%  
- [ ] 标准通道在校准有效期内  
- [ ] 探头、耦合剂、砂纸、π 尺、打印纸齐全  
- [ ] 本户离线包已导入（许可/直报/税期摘要，无原始税票）  
- [ ] 蜂窝开关置于 OFF（默认）

## 到点
1. 开机 → 扫户键/许可二维码 → GNSS 定位  
2. 若距档案坐标超阈：标记 `SOURCE_METER_MISPLACE` 线索，仍可继续比测  
3. 清理管壁 → 测外径/壁厚 → 按 DN 选 V/Z 法安装标准探头  
4. 接被检表：优先 RS485；否则脉冲/电流；再否则人工录入二次表读数（降级模式）  
5. 启动同步采样（稳定流，瞬时波动尽量 ≤5%）  
6. 达最小样本（建议 ≥20 组或规程时长）→ 自动对账  
7. 拍照：铭牌、探头安装、铅封、前后直管段  
8. 确认销号建议 → 打印 → U 盘导出加密包 → 关机收纳

## 不合格处理
- 超差：工单出口指向改表/信号/更正直报/税核/调许可（机内枚举）  
- 仅链路不一致而标准≈被检显示：查 RTU/远传，勿先换表  
- 强制违规：禁止“仅情况说明”归档
