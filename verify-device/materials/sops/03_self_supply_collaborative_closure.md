# SOP-03 规上自备「许可—监测—直报—税费」协同销号

## 目的
解决“有监测≠监测可用”，以及对账超 5% 后处置责任、时限、出口不清的问题。

## 底数比对
| 核对项 | 系统A | 系统B | 是否一致 | 处置 |
|--------|-------|-------|----------|------|
| 电子证照号 | 许可 | — | | |
| 取水口编码 | 许可 | 监测 | | |
| 统计名录ID | 直报 | 许可主体 | | |
| 纳税人识别 | 税费 | 许可主体 | | |

## 月度流程
1. 汇聚当月四方结构化数据（禁止直接投喂原始附件给云端模型）。  
2. 运行校验设备 → 生成偏差与分类。  
3. 相对偏差 >5% 或强制违规 → 县级工单。  
4. 分支出口：  
   - 更正直报  
   - 提请税务复核税基  
   - 调整许可/计划用水  
   - 整改表计/信号/标记停运  
5. 审核模型（或人工）核验证据 → 销号 / 退回。  

## 资产与运维责任
- 厘清政府出资表计与企业自建表计边界，签署运维责任协议。  
- 拒不认领 → 责令限期重新安装。  
- 模拟信号问题突出设备纳入更新清单。

## 指标对齐（管理侧）
- 问题工单当月办结率目标 ≥90%。  
- 违规线索排查销号率 100%。
