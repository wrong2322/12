# 取水计量三方（四方）数据校验设备 — 总流程规程（脱敏版）

> 适用范围：设区市统筹、县（市、区）落地的户级校核。  
> 数据源：许可电子证照、在线监测、用水统计直报、水资源税费。  
> 原则：**监测服务核算，核算对齐公报**；规则优先于模型；原稿与真实台账仅存本地 `private/`。

## 1. 目标闭环

```
户级校核 → 县域核算 → 公报采用 → 双控应用
```

不合格或未销号的偏差数据，不得直接进入统计与核算流程。

## 2. 设备角色（多模型统筹）

| 顺序 | 角色 | 职责 | 可否被模型改写硬规则 |
|------|------|------|----------------------|
| 1 | extractor | 异构台账→统一户对象 | — |
| 2 | reconciler | 四方水量对账与偏差 | 否（阈值配置为准） |
| 3 | classifier | 异常分类与严重度 | 否（强制违规码） |
| 4 | dispatcher | 工单、主办、出口、时限 | 出口须在白名单 |
| 5 | auditor | 销号材料审核 | 材料不齐一律退回 |

编排策略见 `config/models.yaml`：`rules_first: true`。

## 3. 业务三条主线

1. **公共供水**：源头装表/漏损计入、转供对账、县域水量闭合。  
2. **规上自备**：许可—监测—直报—税费协同销号。  
3. **核算衔接**：户级合格数据→县域核算→公报/双控；区域异常溯源到县到户。

## 4. 触发条件（默认）

- 直报与监测或税费相对偏差 **> 5%** → 月度工单。  
- 公共供水转供/闭合超审核阈值 → 季度复核销号。  
- 计量/统计超许可、证照失效、装表不合规、转供不平衡 → **强制派单**。

## 5. 组织分工

- **市级**：统一规则、跨县核实、抽查、规程/案例/标准建议稿。  
- **县级**：点位整改、协议签署、工单办理、县域核算校核。  
- **取用水户/供水企业**：计量运维、台账、检定、直报。  
- **税务**：职责范围内税基复核。

## 6. 运行步骤（本设备）

```bash
cd verify-device
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python src/cli.py samples/households_demo.json
```

输出：`outputs/*.json` + `outputs/audit.jsonl`（全程留痕）。

## 7. 隐私红线

1. 真实申报材料、证照扫描件、税务明细 **不得提交 Git、不得发到公共模型**。  
2. 默认 `local_rules` 提供方，数据不出本机。  
3. 若切换 `openai_compatible`，必须保持 `send_raw_records: false`，只传结构化摘要。  
4. 仓库内仅允许脱敏合成样例（`samples/`）。

## 8. 与核算/公报的边界

- 监测数据承担 **校核** 功能，不直接代替区域用水总量。  
- 经审定的县域核算成果，才作为公报与双控考核采用依据。  
- 山区海岛小型取水口：台账+抄见+抽样，不强制全面远传。
