# SOP-04 监测校核—统计核算—公报采用衔接

## 边界
- 户级校核合格数据 = 核算原料。  
- 监测用于校核，不直接替代区域用水总量。  
- 审定后的县域核算成果 = 公报与双控采用口径。

## 步骤
1. 过滤：未销号偏差户不得进入直接统计汇总量。  
2. 叠加小型用水推算样本，并留存过程说明。  
3. 质量评估核心：公共供水闭合情况 + 规上直接统计质量。  
4. 区域总量/强度异常 → 溯源到县到户 → 整改结果支撑考核数据说明。  

## 设备产出如何被采用
- `batch_summary.json`：本轮超阈/强制/通过统计。  
- 单户 `*.json`：偏差、分类、工单、审核结论。  
- `audit.jsonl`：全流程时间戳，供市级抽查。

## 不做的事
不新建综合性应用平台；依托现有监测、直报、证照、税费协作渠道完成对账与留痕。
