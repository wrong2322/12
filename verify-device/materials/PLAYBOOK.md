# 完整流程套路（器物版一页纸）

## 产品

**TVD-300** 便携多方现场校验终端：标准超声比测 + 被检表直采 + 许可/直报/税摘要对账 + GNSS 断面核验 + 边缘模型销号建议 + 打印/加密导出。

## A. 装备配置

- 主机箱、探头夹具、测厚、采集线、相机、扫码枪、打印纸、校准证书  
- 出车前导入本户**结构化离线包**（真实件只存内网/`private`）

## B. 现场一次作业

```
到点定位 → 管参/装标准探头 → 接被检直采
 → 同步采样 → 机内对账研判 → 拍照取证 → 打印销号单 → 加密导出
```

| 判据 | 器物动作 |
|------|----------|
| 标准 vs 被检超差 | 改表/信号类出口 |
| 被检显示 vs 直采不一致 | 查 RTU/远传链路 |
| 直报/税与计量偏差>5% | 更正直报 / 税核出口 |
| 超许可、证照失效、装表离断面 | 强制工单，禁“仅说明” |

## C. 与现有专利/产品的关系

- 吸收：外夹标准表现场比测、隔离 RS485/脉冲采集、明渠扩展等成熟手段  
- 差异：同一台设备做 **物理真值 + 链路真值 + 业务多方 + 断面空间 + 离线销号证据**  
- 专利布局见 `hardware/patent/`

## D. 样机怎么做起来

1. 阶段 0：买成熟便携超声 + 平板 + 采集模块装航空箱，先跑通流程  
2. 阶段 1：定制结构与采集板，超声协议深对接，送校  
3. 阶段 2：供水点 + 规上点实流验证  
4. 阶段 3：定型、EMC、企标、申报专利
