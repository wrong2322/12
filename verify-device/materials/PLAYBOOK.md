# 完整流程套路（一页纸）

## A. 建设期（底数）

1. 导入许可、监测点、统计名录、税费主体映射 → 问题清单基线  
2. 公共供水：法定断面/漏损手续 + 转供关系表  
3. 规上自备：电子档案 + 运维责任协议 + 模拟信号淘汰清单  
4. 真实材料进 `private/`，只把结构化脱敏 JSON 喂给设备  

## B. 运行期（月/季）

```
结构化入样 → 五模型流水线 → 超阈/强制则派单
     → 县级办理（更正/税核/调许可/改表/转供）
     → 证据包审核 → 销号写回 → 合格数据进核算
```

| 节奏 | 对象 | 动作 |
|------|------|------|
| 月 | 规上自备偏差>5% | 工单，办结率目标≥90% |
| 季 | 公共供水闭合超阈 | 县级复核，跨区域市级核实 |
| 持续 | 超许可/失效证照等 | 强制排查销号 100% |

## C. 应用期（核算出口）

户级合格 → 县域核算（含推算说明）→ 审定 → 公报/双控同口径  
区域异常必须能溯源到县到户；未销号偏差不得直接入库。

## D. 多模型怎么“统筹”

1. **规则先算**：偏差、强制违规码  
2. **模型后补**：原因细拆、工单话术、证据审核  
3. **冲突升级**：分类与派单矛盾 → 人工/市级抽查  
4. **默认本地**：`local_rules`；云端只传摘要  

命令：`python src/cli.py samples/households_demo.json`
