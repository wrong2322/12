# 流程套路（加装常驻版）

## 方案定性

**现场加装 TVD-Gate，连续三方校验**；便携比测只作验收/抽检辅具。

```
方① 外夹核查表（加装，独立测） 
方② 原表→RTU 只听镜像（加装分接，故障直通）
方③ 直报 + 纳税水量摘要（县里下发/巡检写入）
      + 许可配额边界
        → Gate 内闭合 → 超阈/强制事件 → 销号线索
```

## 建设

1. 按问题清单选点（不平均撒点）  
2. 不停水抱箍装外夹核查通道 + 防护罩  
3. 串入故障直通只听分接（原远传保持）  
4. 装 Gate 箱、供电防雷、铅封  
5. 接通方③摘要通道（汇聚下发 / U 盘 / 接口订阅）  
6. 验收：原平台不断数；三路有数；基线偏差入库  

## 运行

| 周期 | 设备自动做什么 |
|------|----------------|
| 分钟 | ① vs ② 一致性、离线/跳变 |
| 日 | 累计闭合、异常大数据 |
| 月/税期 | vs ③ 相对偏差，>5% 出工单事件 |
| 持续 | 超许可、证照失效等强制线索 |

## 钱往哪花

单点约 2.4–7 万（见 `hardware/addon/bom/BOM_GATE_S.md`），投问题点位；非实物支出做规则、汇聚摘要与销号机制。

## 明确不做

- 不靠“到场比测一次”代替常态校验  
- 不拆原表作唯一手段、不新建大而全平台  
- 不加装故障拖死原监测远传
