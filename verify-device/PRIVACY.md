# 隐私与可见性说明

本目录配套的校验设备按「仅自己可见 / 不外发」设计。

## 已隔离（不会进入 Git）

- 仓库根目录 `private/`（含申报原稿、原始导入、导出）
- 所有 `*.docx` / 未声明的 `*.xlsx`
- `.env`、密钥、`secrets/`、`raw_data/`、`exports/`

## 允许进入版本库的内容

- 脱敏合成样例 `samples/`
- 流程规程、表单模板、提示词（不含真实户名与真水量）
- 源代码与配置（阈值、路由）

## 运行时

- 默认 `local_rules`：推理在本地完成，无 API 调用。
- 云端模型适配器默认 **拒绝** 发送 `raw_text` 原始台账。
- 审计日志只记结构化字段与工单号。

## 使用建议

1. 真实市县数据只放 `private/raw_inputs/`。  
2. 需要给同事看流程时，只分享 `verify-device/` 脱敏包，不要附带 `private/`。  
3. 若仓库本身为公开模板，请将本项目迁到私有仓库，或仅本地使用、不要 push 含真实数据的分支。
